01 / API

从平台取得记录

Meta Ads API 提供权限允许的资源与报表。自行集成还需维护授权、请求处理，以及需要的存储与更新流程。

02 / MCP

让 AI 调用数据工具

MCP 规定客户端如何发现和调用工具。实际覆盖、更新速度和是否保存历史，取决于工具背后的服务实现。

03 / HOLOGROW

持续准备回答背后的依据

Hologrow 拉取可用 Meta Ads 数据，整理字段与业务键，维护定期同步，再通过只读 MCP 提供可检查的数据表。加入其他已连接来源时，保留各自的口径和覆盖范围。

这是相互配合的不同层次。其他来源 MCP 也可能提供额外服务，应比较其具体实现。Hologrow 不绕过源端权限，也不会让不同指标自动变成同一口径。

FAQ

Meta Ads MCP 集成常见问题

Hologrow 能抓取哪些 Meta Ads 指标？

产品目录展示 40 张 Meta Ads 表。已确认包含账户每日 Insights、年龄／性别、国家、设备平台与投放平台拆分，以及对应 Metrics 表。创意素材覆盖仍需核对所需字段，不能仅凭这些表名推断。

AI 会自动给好广告加预算吗？

不会。Hologrow 工具读取已同步数据，支持复核流程，不执行自动出价、预算调整或创意发布。

这个 Meta Ads MCP 集成包含创意和人群拆分吗？

已确认的人群拆分包括年龄／性别与国家，也有设备和投放平台报告，可用于定位不同细分维度的表现变化。创意素材及创意级字段请另行核对工作区 Schema。

AI 能对照 Meta 归因转化与店铺订单吗？

可以将可用报告与已连接店铺记录并列，指出日期、归因与退款差异。平台归因转化不等于一一对应的全部店铺订单，同步趋势也不能证明因果增量。

可以在同一 AI 流程中比较 Meta Ads 与 Google Ads 吗？

连接两端后先检查 Meta 表覆盖，在一致周期和币种下比较可对照的花费，并分别呈现平台转化定义。Hologrow 提供共享数据访问，不会自动把不同归因模型变成同一种模型。

Meta Ads API 与 MCP 连接有什么区别？

API 向程序提供 Meta Ads 的资源与报表；MCP 让 AI 客户端发现并调用工具，这些工具可以直接查询 API，也可以查询已存储的数据层。MCP 协议本身不保证定期同步、历史保留或跨源映射。Hologrow 负责连接来源、维护可用的同步表，再通过托管 MCP 提供只读工具。

为什么用 Hologrow，而不是自己接 Meta Ads API？

有能力维护授权和请求逻辑时，直接调用 API 可以满足单次、明确的查询。持续复盘 Meta Ads 还需要拉取、存储、更新、可用历史和明确字段定义。Hologrow 维护这层数据准备工作，并让表级覆盖可检查，使 AI 能沿已有依据继续追问、加入其他已连接来源。价值在持续维护的数据层，不是声称 API 数据更不准确。

Hologrow MCP 提供实时 Meta Ads 数据或无限历史吗？

不提供这样的保证。AI 查询已经同步到 Hologrow 的数据；刷新计划与可回填历史因来源和数据表而异。请在 Data Explorer 检查最近成功同步和覆盖日期。MCP 端点已连接，不会消除源 API 权限、报表延迟或历史窗口限制。

如何将 Meta Ads 连接到 Claude、ChatGPT 或 Codex？

先在 Hologrow 授权 Meta Ads，到 Data Explorer 核对可用表和日期，再按所选 AI 客户端指南添加 Hologrow。AI 通过托管 MCP 连接查询已同步数据。
