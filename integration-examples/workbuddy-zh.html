06 / 安全与控制

WorkBuddy 只读数据，控制权在你手中。

授权数据连接，账户操作仍由你决定。

连接凭据加密保存

Hologrow 加密保存源连接凭据，AI 访问范围跟随授权连接的 Hologrow 用户。

源数据访问保持只读

通过 Hologrow 分析已同步记录，不修改出价、预算、商品或订单。执行前请复核 AI 结论。

随时撤销访问

在 AI Platforms 轮换或撤销 MCP key，不要将 key 写入报告或共享项目文件。

AI 客户端与模型提供方有各自的权限和数据政策。Hologrow 的只读边界适用于其提供的工具。

07 / 常见问题

WorkBuddy 集成常见问题

连接方式、实际工作流程，以及首次分析前需要核实的内容。

Hologrow WorkBuddy MCP 连接是什么？

它让 WorkBuddy 桌面端通过 Hologrow 工具读取已同步经营数据，可用于整理带有证据和优先检查项的运营简报。

为什么要在 WorkBuddy 开启 Trust？

Hologrow 连接指南要求为对应 MCP 连接器开启 Trust，WorkBuddy 才能使用工具。该设置不会改变 Hologrow 的只读数据边界。

WorkBuddy 的 MCP key 从哪里获取？

在 Hologrow AI Platforms 创建。仅用于指南中的客户端配置，不应出现在分享的报告中；不再需要连接时可轮换或撤销。

WorkBuddy 可以整理可用的行动清单吗？

可以要求每项都写明变化、来源、相关日期与下一步检查。AI 负责整理，负责人应验证解释并决定是否执行。

这里是否代表连接后就会自动生成日报？

不代表。这里展示的是可向 WorkBuddy 提出的任务。定期执行取决于客户端设置与权限，Hologrow 的源数据同步则独立进行。

WorkBuddy 找不到 Hologrow 工具怎么办？

确认安装完成、key 有效，并在 Configure MCP 开启 Trust。先验证已连接平台，再排查具体数据表。

能修改订单或暂停广告吗？

不能通过 Hologrow 执行。其 MCP 工具读取已同步记录，建议本身不会修改店铺或广告设置。

简报应该如何处理缺失的广告数据？

应明确标注缺口并限制结论。例如结算中的费用记录不能代替广告活动级报告，也不能据此判断某个活动表现。
