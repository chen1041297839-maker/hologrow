07 / QUESTIONS, ANSWERED

WorkBuddy integration FAQ

Connection details, practical workflows and what to verify before your first analysis.

What is the Hologrow WorkBuddy MCP connection?

It lets the WorkBuddy desktop app read synchronized commerce data through Hologrow tools. A useful workflow is a concise operations brief with evidence and priority checks.

Why must I enable Trust in WorkBuddy?

The Hologrow setup guide requires Trust to be enabled for its MCP connector so WorkBuddy can use the tools. This does not change Hologrow’s read-only data boundary.

Where do I get the WorkBuddy MCP key?

Create it in Hologrow AI Platforms. Use it only in the documented client setup, keep it out of shared reports and rotate or revoke it if you no longer need the connection.

Can WorkBuddy create a practical action list?

Ask for the change, source, relevant date range and next check for every item. The AI prepares the brief; a human owner should validate the explanation and decide whether to act.

Does this page promise a scheduled daily report?

No. The examples are tasks you can request in WorkBuddy. Recurring execution depends on your client setup and permissions, while Hologrow’s source synchronization runs independently.

What if WorkBuddy cannot find Hologrow tools?

Confirm installation completed, the key is valid and Trust is enabled in Configure MCP. Verify connected platforms before investigating a specific data table.

Can it change an order or pause an ad?

Not through Hologrow. Its MCP tools read synced records; suggested actions do not modify store or advertising settings.

How should a brief handle missing advertising data?

Label the gap and limit the conclusion. For example, a settlement fee line does not replace campaign-level advertising reports or establish a campaign’s performance.
