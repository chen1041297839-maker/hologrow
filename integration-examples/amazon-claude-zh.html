阅读产品文档
连接前需要准备什么？+

需要 Hologrow 账户、相关 Amazon 账户的授权权限、至少一个正在 Data Explorer 中同步的数据源，以及允许使用连接器的 Claude 工作区。Team 或 Enterprise 工作区可能需要管理员先添加 Hologrow。

连接 Seller Central 后，也能直接读取广告数据吗？+

涉及广告花费、广告活动或关键词表现时，需要单独连接 Amazon Ads。连接 Seller Central 不代表广告表已经可用，请在 Data Explorer 和 Data Schema 中分别确认。

Claude 查不到数据时怎么办？+

先检查 Hologrow 中的账户授权和同步状态，再确认需要的数据表及日期范围是否可用，最后检查 Claude 连接。初次历史同步可能仍在进行，应先说明数据缺失或过期，再做判断。

Hologrow 会修改我的业务账户吗？+

不会。Hologrow 读取已同步数据，不修改出价、预算、商品、库存或源账户设置。分析和建议由你的团队审核。

数据多久更新？+

Hologrow 定期进行增量同步并回填历史数据。报告何时可用取决于数据源、账户和数据表。比较不同时段前，请在 Data Explorer 检查最近成功同步时间及覆盖日期。
